Upgrade the SDK and move software packaging onto block-tools

Catalog bumps: `@platforma-sdk/model` and `ui-vue` 1.79 → 1.81, `workflow-tengo`
6.7.1 → 6.8.2, `block-tools` 2.12.4 → 2.12.13, `tengo-builder` 4.0.16 → 4.0.22,
`ts-builder` 1.6.0 → 1.6.2, `ts-configs` 1.3.0 → 1.4.0, `helpers` 1.14.3 →
1.14.5, `package-builder` 3.14.1 → 3.14.2, `test` 1.79.34 → 1.81.2.

All nine software packages move from `pl-pkg` / `@platforma-sdk/package-builder`
to `block-tools software build`, using `shx` so the pack steps are
cross-platform. The build scripts are regenerated by the structurer: `build:dev`
becomes `build:dev-local`, with `build:release` used before publish.

Two model-side API changes had to be absorbed:

- `TreeNodeAccessor.resolveAny` was removed. `traverse` is its documented alias
  and does not assert a field type, so it is the faithful replacement (`resolve`
  would have defaulted to Input).
- `ResultPool.getAnchoredPColumns` now types its column data as possibly
  `undefined`. The local `Column` alias was widened to match; the columns are
  passed to `createPFrameForGraphs`, which accepts unresolved data as-is.
